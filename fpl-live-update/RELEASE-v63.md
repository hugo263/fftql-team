# v63 — 比赛中心首页（2026-09-13）

用户先请求本地设计，随后明确「直接上线」。未使用 baoyu-design。

## 已发布

- `/discover`（现有前后台左上角 Logo 目的地）改为深绿 / 青柠双栏比赛中心；`/` 及 `/?league=ID` 仍为原 Draft 工作台，后台不改。
- 左侧官方比分、日期、GW、进行中与本浏览器关注筛选；点击比赛联动右侧。
- 右侧 G/A、红黄牌、CS/零封失去、DC 事件。首次采集是本场累计，随后差分才标本站检测时间，不伪造逐球发生分钟。
- 单条 / 当前筛选分享 PNG，1080px 宽、自适应高度、最多5条并标截取数量。图上包含原Logo、源快照时间、比赛比分、球员该项得分、网站地址、延迟/结算标记；复制失败提供下载，不自动发送。
- 保留联赛 ID / 官方链接查找、ID 说明、问题反馈和匿名统计。没有公开后台入口。

## 后端边界

新 `match-centre.js` 只使用 Classic bootstrap、全季 fixtures 和对应 GW live，同一球员 ID 空间。`GET /api/match-centre?gw=1..38`；缺失参数默认实际正在比赛或最近开赛轮。

- 比赛源缓存60秒，bootstrap15分钟；同轮合并并发，最多3个不同GW刷新、4个并行上游请求。
- 最多3轮缓存，固定保留默认当前GW；最多2,000条观测事件/轮。仅新文件 `data/cache/match-centre-v1.json` 持久化观测，不改现有快照或 TOTW 归属。
- 服务启动和每60秒观察默认GW，不依赖浏览器停留。缺失数据不伪造0，失败保留源时间并标stale。
- 零封撤销只在已观察到官方该项得分从正变零时产生；球员整份明细缺失不能撤销。换下保留零封由官方解释得分决定，不凭球队比分推断。
- DC依据官方解释分，不将防守动作次数当得分，不额外加至球员总分。红牌与黄牌按官方明细避免重复扣分；页面不将各条事件求和冒充球员总分。
- 默认/手选GW互相隔离，前端轮询保持筛选。浏览器隐藏时暂停自身轮询，服务端仍继续观察。
