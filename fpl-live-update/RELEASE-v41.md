- 新增三张固定卡片：今日浏览量 PV、今日用户 UV、累计使用联赛。今天按 Asia/Shanghai 自然日 00:00 至当前时刻；UV 是已有 HMAC(ip|ua) 匿名访客估算，非账户数/精确人数。
- 7/30/90 天筛选控制下方范围指标，使用包含当天的自然日；PV 与趋势和小时汇总一致。今日卡片与累计去重联赛数不随筛选变化。快速切换时旧响应不能覆盖新筛选，失败保持旧数据并提示，不显示假零值。

- 登录或使用已登录后台时自动登记匿名访客并签发专门的长期排除 cookie。退出后台继续排除，带签名标记的浏览器换 IP/UA 也会重新登记。其他设备/浏览器需要登录一次。已识别 ID 的旧事件追溯过滤；不能可靠识别的旧本人访问不做猜测。
- 同一套过滤用于今日、时段、趋势、来源、最近活动和联赛数。只由服务端判断 internal，不信任客户端声明。排除 cookie 与 admin session 的签名域不同，不授予后台访问；生产设置 HttpOnly / Secure / SameSite=Strict。
- 公共 analytics.js 复用旧 session 存储键，同时覆盖工作台与 discover。只统计实际页面白名单；来源只发送 origin，不发送私有 URL 查询参数。隐藏页面不累加停留，pagehide 不重复计时。未改 discover 设计或独立资讯原型。
