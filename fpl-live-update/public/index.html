怎么查找联赛 ID？

需要的是 Draft 联赛的数字 ID，不是球队 ID，也不是加入联赛的邀请码。

我是联赛管理员

  1. 在浏览器打开并登录 官方 FPL Draft ↗，找到你的联赛。
  2. 打开联赛的 Edit（编辑） 页面，查看浏览器地址栏的完整网址。
  3. 找到 /league/ 后面的数字，这就是联赛 ID。复制数字，回到本页输入即可。
网址示例draft.premierleague.com/league/47275/edit

这个示例的联赛 ID 是 47275；请使用你自己网址中的数字。

我是普通联赛成员

没有 Edit 入口？最简单的办法是请联赛管理员按上面的步骤，把数字 ID 发到群里。同一联赛的所有成员使用同一个 ID。

电脑上自行查询（进阶方法）
  1. 登录官方 Draft 并打开浏览器开发者工具，切换到 Network（网络）。
  2. 进入目标联赛或刷新联赛页面，在网络请求中搜索 details。
  3. 找到该联赛的 /api/league/数字/details 请求；其中的数字就是 ID。若出现多个结果，查看响应中的联赛名称确认。

只需要复制数字，无需向本站提供密码、Cookie 或登录信息。
