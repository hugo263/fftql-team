# TQL FPL 资讯第一版

目标地址：`https://news.fftql.team`。新闻站使用独立数据库和服务；后台登录与主站共用，Draft 数据和资讯管理为并列模块。

基于 [AIHOT](https://github.com/KKKKhazix/AIHOT) 的 MIT 代码，固定上游版本 `c38705b84058c53bc75c91e6b0faa71c3079f588`。保留 LICENSE、NOTICE 与字体许可；页面使用 TQL 品牌。

## 已实现

- Fantasy Football Scout、AllAboutFPL RSS 采集，保留原始发布日期与链接，生成中文标题和摘要；原站全文不公开转载。
- 八类资讯、玩法（Classic / Draft / 通用）、证据状态、球队、球员、GW 标签；筛选、搜索、收藏、事件归组与日报沿用上游流程。
- FPL 官方现价每十分钟观测：第一次建基准，同赛季连续成功观测有差异才记录涨跌。保存前价、现价、发现时间和前次观测时间；不推测准确发生时间，不将赛季累计变化当作当天涨跌。
- 球员以官方稳定 `code` 存储；此版不读取私人球队或登录 FPL 账号。选秀与价格内容按玩法分开。
- 数据来源目录标明自动接入与原站阅读。其他媒体与价格预测站尚未接入自动采集。
- 网页通过 API 读取公开数据。数据库与模型密钥只由后端进程持有，读者打开页面不会调用模型。

## 部署方式

按用户 2026-09-30 的指示，直接使用现有腾讯云服务器，不创建或购买 CloudBase 套餐。

1. 服务器 `124.222.221.150` 的 PostgreSQL 15 使用独立的 `tql_news` 数据库和 `tql_news_app` 账号。账号只管理新闻站数据库，没有超级用户、创建数据库或创建角色权限。数据库仅监听 loopback；新闻站不访问既有应用数据库。
2. DNS：`news`，A，`124.222.221.150`，使用现有 DNSPod 解析；无需新套餐。
3. 服务器目录 `/opt/tql-news/releases/<release>`，符号链接 `current`；独立 systemd 服务 `tql-news-api`、`tql-news-web`、`tql-news-worker`。API 9011、网页 9012 均监听 loopback。
4. 后端密钥在 `/etc/tql-news/app.env`（0600）；网页只读独立 `web.env`。配置模板与服务文件见 `deploy/tql-news/`。模型使用服务器既有 Qwen 连接，并设置请求预算。
5. 使用服务器现有 Node 24，执行 `npm ci --omit=dev`。服务器安装 Linux 原生依赖，使用本机已构建的网页文件。
6. 保持采集与模型阀关闭，执行迁移、种子、`scripts/fpl-launch-budget.ts` 和页面冒烟检查。
7. DNS 就绪后使用现有 Certbot 账户和 `/var/lib/letsencrypt` 申请子域名证书；只新增 `tql_news.conf`，先 `nginx -t` 再 reload。
8. 开启 worker，检查两份 RSS 的成功记录、价格基准、模型回执及公开页面；执行 HTTPS 冒烟检查后才报告上线完成。

## 后台整合（v3）

- 统一入口 `https://fftql.team/admin`，两个并列模块为“Draft 数据”和“资讯管理”。保留原 Draft 访问统计与联赛使用数据。
- 资讯管理 `https://news.fftql.team/admin`；登录页连接到既有 Draft 管理员登录。原管理员 Cookie 仍只适用于主站。
- Draft 使用服务端专用密钥签发一分钟、一次性的 POST 登录凭据；验证固定来源和接收站点，并拦截重复使用。资讯会话不超过原 Draft 会话到期时间，后台写操作继续检查 CSRF。退出资讯后台清除资讯会话，Draft 登录独立保留。
- 前台移除 Agent 接入、数据来源、关于；迁入 `/admin/agent`、`/admin/source-directory`、`/admin/about`。页面和 loader 数据均检查管理员登录、禁止缓存与索引。旧地址跳转后台。
- 资讯后台总览包含价格采集状态及内容、来源、模型预算、任务和站点说明入口。
- Classic 外卡、Free Hit、Triple Captain、Bench Boost 不再因“draft team”误标为 Draft；明确比较 Draft 联赛的文章保留两种玩法。
- 全新隔离库 169 项后端测试、17 项网页行为测试、2 项 Draft 签发测试通过；类型检查与生产构建通过。模型测试仅使用本机模拟服务，并禁止外部网络。
